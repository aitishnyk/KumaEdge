# Branding and GitHub social preview

Original MIT assets: [dark logo](assets/branding/logo-dark.svg), [light logo](assets/branding/logo-light.svg), [icon](assets/branding/icon.svg), [banner](assets/branding/banner.svg), [social preview](assets/branding/social-preview.png). [Attribution](assets/branding/LICENSE.md). No favicon is added because the current gateway does not consume one.

Social preview is 1280 × 640 PNG under 1 MB, composed from original artwork and a proportionally resized actual DEMO screenshot. GitHub REST repository settings do not expose a documented social-preview upload field. If browser settings access does not permit upload, an owner can set it manually:

GitHub browser settings access was unavailable (signed-out browser); the asset is prepared, not installed. See the [official upload instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

1. Open https://github.com/aitishnyk/KumaEdge/settings.
2. Under **General → Social preview**, choose **Edit → Upload an image**.
3. Select `docs/assets/branding/social-preview.png` from this clone.
4. Verify the crop and save.

Do not claim the preview is installed merely because the asset is committed. Description, homepage and topics can be updated separately through repository settings/API.

Screenshot provenance: DEMO desktop/mobile and login are captured from the actual reference application; OWNER and themed Status Page are from a fresh, disposable local Kuma 2.5.7 dataset with no private monitor targets or owner credentials visible. No availability values are drawn or edited into screenshots. The live reference Status Page is not themed automatically.
