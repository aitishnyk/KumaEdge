# KumaEdge

> An open-source, edge-first uptime monitoring project, targeting Bunny.net without a self-managed VPS.

**Project status: pre-alpha / architecture and implementation in progress.** No production monitoring or one-click deployment is available yet.

KumaEdge is an independent project inspired by [Uptime Kuma](https://github.com/louislam/uptime-kuma). This repository was created as a new repository, **not** a GitHub-native fork. Future reuse of upstream source must retain all relevant licenses and attribution.

See [the roadmap](docs/ROADMAP.md), [architecture](docs/ARCHITECTURE.md), and [security policy](SECURITY.md).
